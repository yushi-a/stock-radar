# スクリーニング条件

判定基準：「現在の株価が数年後に何倍にもなりそうか」。
構成は「共通足切り」＋「2トラック（黒字割安型／高成長型）」＋「タイミング加点」の3層。

## 根拠にした研究

### 米国：Yartseva (2025) "The Alchemy of Multibagger Stocks"（CAFÉ Working Paper No.33, Birmingham City University）

- 対象：2009〜2024年に10倍以上になった米主要取引所上場の464銘柄。
- 小型・割安・高収益が有意（Fama-French の size / value / profitability）。
- FCF 利回りが最も強い予測変数。book-to-market（B/M）も有力。
- EBITDA・EPS・FCF/株 の**成長率は有意でなかった**（最終モデルから除外）。
- 資産成長率が EBITDA 成長率を上回ると、翌年リターンが平均約23pt低下。
- 3・6ヶ月モメンタムは負の係数。12ヶ月高値付近は劣後し、12ヶ月安値付近・直近6ヶ月下落後が起点になりやすい。
- 起点の時価総額の中央値は約 $348M。
- 注意：期末時点でも10倍を維持した銘柄のみを抽出しており、生存者バイアスがある。低金利局面が中心。

出典：
- https://ideas.repec.org/p/akf/cafewp/33.html
- https://newsletter.stablebread.com/p/research-on-464-10-baggers
- https://www.quantseeker.com/p/how-multibaggers-really-happen

### 日本：岡三証券「未来のテンバガーを探す」（2023/9/14）

- 対象：2012年末〜2022年末に10倍以上になった82社（分析対象は75銘柄）。
- 2012年末時点の中央値（テンバガー群 vs 全上場企業）：
  - 時価総額 35億円 vs 100億円
  - 上場経過年数 6.8年 vs 12.3年
  - 売上 CAGR（過去3期） 8.8% vs 3.3%
  - ROE 8.8% vs 5.2%
  - PBR 1.43倍 vs 0.85倍
  - PER 14.4倍 vs 14.2倍
- オーナー系企業が約7割（p.2 図表4）。
- 同資料のスクリーニング条件（p.3）：時価総額50億〜500億円、過去3期売上 CAGR 10%以上、直近期の営業利益率5%以上、上場5年未満、創業者等が大株主上位3位以内。

出典：https://www.okasan.co.jp/marketinfo/data/pdf/seminar/20230914.pdf

## ② トラックA：黒字・割安型（Yartseva 準拠）

| 指標 | 条件 |
|---|---|
| 売上 3年 CAGR | ≥ 10% |
| 営業利益率 | > 0%（日本は ≥ 5%） |
| FCF 利回り | ≥ 4%（P/FCF ≤ 25） |
| PBR | ≤ 2.5（B/M ≥ 0.4） |
| ROA / ROE | ROA ≥ 5% または ROE ≥ 10% |
| 資産成長率 − EBITDA 成長率 | ≤ 0（プログラムで計算） |

### 評価スキルの①成長性とは前提が違う（2026-09-23 決定：据え置き）

売上3年CAGR の下限10%は、評価スキル `growth-stock-evaluation` の①成長性のルーブリック
（`references/scorecard.md`）では**3〜4点の帯**に入る（「成長10%未満」が3〜4点、「15〜25%」が5〜6点）。
①の加重は0.20なので、トラックA候補はトラックB候補より総合で0.6〜1.0点低く出るのが構造上の前提になる（#55）。

これは不具合ではなく前提の違いである。Yartseva は成長率を有意でないとしてモデルから外しており、
トラックAが選んでいるのは「低成長・高FCF利回り・低PBR」という、まさにその特徴を持つ銘柄である。
評価スキルは成長性に0.20を配分しているので、同じ特徴を減点する。

**下限は10%のまま据え置く。** 理由：

- 15%に上げると、2026-09-21 の run のトラックA 8件のうち残るのは NRDS の1件だけだった。
  トラックAが実質なくなり、Yartseva の知見を捨てることになる
- ①が見るのは直近4四半期の前年同期比で、3年CAGR とは別の数字（SON は3年CAGR 11.8% だが直近の前年比は41.7%）
- どちらの前提が実際のリターンに効くかは、スコアと実績を蓄積しないと判断できない
  （`docs/skill-integration.md` の「フィードバック」。第一弾より後）

評価スキルにかけた結果は、**トラックA/B を分けて読む**。トラックA候補の総合スコアをトラックB候補と横に並べて比べない。

## ③ トラックB：高成長型（赤字許容）

実証研究の裏付けは弱い。日本データの「高い売上成長」と既存評価フレームからの見解。

| 指標 | 条件 |
|---|---|
| 売上成長率（YoY） | ≥ 25%、かつ予想も ≥ 20% |
| 営業利益率 | ≥ −20%（評価スキルの PSR 切替境界と一致） |
| 粗利率 | ≥ 40% |
| PSR | ≤ 8 |
| 財務余力 | 自己資本比率 ≥ 50% または 流動比率 ≥ 1.5 |

## ④ タイミング加点（除外ではなく並べ替え用）

- 52週高値からの下落率 −20%〜−50%
- 52週レンジ内位置（(株価−安値)/(高値−安値)） ≤ 50%
- 日本：上場10年以内、オーナー系企業（大株主上位3位に創業者・経営者）を加点

業績悪化による下落と区別できないため、ハードフィルタにはしない。

### スコアリング方法（2026-09-21 決定）

**満たした条件の数をそのまま点にする（0〜2 の整数）。** 同点は52週レンジ内位置の昇順、
つまり52週安値に近い順に並べる（Yartseva の「12ヶ月安値付近が起点になりやすい」に沿う）。

連続値の重み付けは採らない。下落率は「深いほど良い」ではなく帯（−20% に届かないのは高値圏、
−50% 超は業績悪化の疑い）なので、連続化すると山形の関数の頂点と裾を根拠なく決めることになる。
2つの指標はどちらも「高値からどれだけ離れたか」を見ており重複が大きく、重みを分けても順位は
ほとんど変わらない。恣意性を閾値だけに閉じておけば、帯をずらした影響が
`screen_runs.criteria_snapshot` から読める。

## 定義上の注意

- **3年 CAGR**：累積+33% ≒ 年率10%。ツールによって「3年前比の累積」「2年間の年率」など定義が異なるので、自前計算に統一する。
- **FCF**：営業CF − 設備投資。J-Quants のサマリーでは設備投資が無いため、簡易的に「営業CF＋投資CF」で近似する（近似であることを出力に明記）。
- **ROA**：分子を純利益に統一する（SBI 証券の国内株は経常利益ベースなので注意）。

## 米国版の読み替え（2026-09-20 決定）

米国先行で実装するにあたり、上記の条件表は2箇所そのままでは実装できない。以下で代替する。
判断の経緯は `docs/architecture.md`、未決分は `docs/open-questions.md` を参照。

| 元の条件 | 米国での扱い | 理由 |
|---|---|---|
| トラックB：予想売上成長率 ≥ 20% | **直近四半期 YoY ≥ 20%** | 会社予想は日本の決算短信固有。米国の 10-K/10-Q にガイダンスは含まれず SEC XBRL から取得不可能。「成長が失速していないこと」という意図は四半期実績で保てる |
| トラックA：資産成長率 − EBITDA成長率 ≤ 0 | **資産成長率 − EBIT成長率 ≤ 0**（前期営業赤字からの黒字転換は通す） | 減価償却費は XBRL のタグ揺れが最も激しい科目（`DepreciationDepletionAndAmortization` / `DepreciationAmortizationAndAccretionNet` / CF計算書のみ / 未開示）。`OperatingIncomeLoss` はタグが安定しており、Yartseva の「資産を膨らませているのに収益が伴わない企業を外す」趣旨は EBIT でも保てる。後から EBITDA に差し替えられる設計にする |

その他の米国固有の実装上の決定：

- **会計期間**：年次（10-K）を主とする。Yartseva も年次ベース。四半期（10-Q）はトラックB の売上 YoY にのみ使う。
- **時価総額**：`dei:EntityCommonStockSharesOutstanding`（XBRL 表紙の発行済株式数）× 株価で自前計算する。yfinance の `marketCap` は照合にのみ使う。
- **業種除外**：SIC コード 6000番台で金融・REIT を除外する。
- **ADR 除外**：10-K 提出企業のみを対象とする（20-F/6-K 提出企業は開示頻度・会計基準・XBRL の揃い方が異なる）。
- **売上ゼロ除外**：臨床段階のバイオテックや SPAC は売上基準の指標がすべて計算不能になるため除外する。
